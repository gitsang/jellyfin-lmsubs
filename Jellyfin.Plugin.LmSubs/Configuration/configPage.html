LMSubs — ASR Transcription & LLM Subtitle Translation

Both stages use OpenAI-compatible APIs. Pick a provider (its default URL is used when Base URL is left empty), or choose OpenAI Compatible (custom) and enter any endpoint up to /v1 — the plugin appends /audio/transcriptions and /chat/completions automatically.

Works like OpenSubtitles: item menu → Edit Subtitles → pick a language (it becomes the translation target) → search → download the LM Subtitles entry. The server then transcribes and translates the whole video; when finished, the subtitle is saved and appears in every client's subtitle selector. Completed results are cached — downloading again never re-calls the API. While generating, search again to see progress in the entry's description.
