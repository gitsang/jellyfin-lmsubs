LMSubs — ASR 语音转写 & LLM 字幕翻译

所有接口均为 OpenAI Compatible：Base URL 填到 /v1 即可（插件自动拼接 /audio/transcriptions 与 /chat/completions，填完整 endpoint 也兼容）。

无需修改 Web：插件会在视频的字幕列表里加入两条字幕轨—— 「LM 字幕」（选择即从当前播放位置开始转写＋翻译，已生成的部分直接用缓存，全部完成后不再调 API）和 「LM 字幕（实时）」（每次选择/拖动进度都重新转写并覆盖）。 在任意客户端的字幕选择器里选中即可，字幕会随生成逐步补齐（拖动一下进度条可立即刷新）。

语音识别 ASR

例：https://api.openai.com/v1 、https://api.siliconflow.cn/v1 、http://127.0.0.1:8000/v1
例：whisper-1、gpt-4o-transcribe、SenseVoiceSmall、FunAudioLLM/SenseVoiceSmall
ISO-639-1，如 en / ja / zh
按此长度用 ffmpeg 切分音频，从当前播放位置的段开始逐段请求 ASR。想更快出字幕可调小（120–300）。

翻译 LM Translate

例：gpt-4o-mini、deepseek-chat、Qwen/Qwen2.5-7B-Instruct
如 Chinese (Simplified) / 简体中文 / English / 日本語
保留最近 N 条「原文 → 译文」作为对话上下文，保持人名/术语一致。0 = 关闭。
例：保留英文人名；口语化；不要解释。
